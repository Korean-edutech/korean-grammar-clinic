[난이도: 초급~중급 (TOPIK 1~4급)]

[챗봇 핵심 지시사항: 사용자가 특정 불규칙을 묻지 않고 "불규칙에 대해 알려줘"라고 광범위하게 질문하면, 한 번에 1~2개의 불규칙만 설명하세요. 그리고 반드시 꼬리질문으로 "다음에는 'O 불규칙'에 대해 알아볼까요?"라고 유도해서 학습자가 천천히 소화하게 만드세요.]


[카테고리 1: 기본형 (난이도: 초급 1급)]
동사와 형용사는 활용을 해.
동사와 형용사 모두 기본형은 '다'로 끝나는데 활용을 할 땐 '다'가 없어지고 뒤에 다른 문법들이 붙어.
그때 붙는 문법 중 가장 많이 쓰이는 것 중 하나는 '아요'와 '어요'야.
'아요'는 앞에 오는 글자의 모음이 'ㅗ', 'ㅏ'인 경우에 붙고,
'어요'는 앞에 오는 글자의 모음이 그 외의 것인 경우에 붙어.

알다 -> 알아요
골다 -> 골아요
닮다 -> 닮아요
속다 -> 속아요

먹다 -> 먹어요
숨다 -> 숨어요
섞다 -> 섞어요

앞글자의 받침이 없으면 축약하거나 생략한 형태로만 써.
오다 -> 와요(축약)
게우다 -> 게워요(축약)
가다 -> 가요(생략)
자다 -> 자요(생략)


[카테고리 2: 불규칙형 (난이도: 초급 2급)]
[1단계: 모양이 사라지는 탈락 규칙 ('ㅡ', 'ㄹ')]
* 'ㅡ' 탈락 (ㅡ Drop)
- 규칙: 어간의 끝 모음 'ㅡ'가 '아/어'를 만나면 'ㅡ'가 사라집니다. (앞 음절 모음이 'ㅏ, ㅗ'면 '아요', 아니면 '어요'가 붙습니다.)
- 예문 1: 바쁘다 -> 바빠요 (요즘 일이 너무 바빠요.)
- 예문 2: 쓰다 -> 써요 (공책에 이름을 써요.)

* 'ㄹ' 탈락 (ㄹ Drop), ('아요/어요' 앞에서는 안 사라집니다. 해당 문법 항목에서는 불규칙이 적용되지 않는 부분입니다.)
- 규칙: 어간의 끝 자음 'ㄹ'이 'ㄴ, ㅂ, ㅅ'으로 시작하는 문법을 만나면 'ㄹ'이 사라집니다.
- 예문 1: 살다 -> 사세요 (어디에 사세요?)
- 예문 2: 만들다 -> 만듭니다 (한국 음식을 만듭니다.)

[2단계: 모양이 바뀌는 불규칙 ('ㅂ', 'ㄷ', '르')]
* 'ㅂ' 불규칙 (ㅂ Irregular)
- 규칙: 어간의 끝 자음 'ㅂ'이 모음을 만나면 '우'나 '오'로 바뀝니다. (대부분 '우'로 바뀌어 '워요'가 됩니다. '돕다', '곱다' 등의 단어만 '도와요', '고와요'가 됩니다.)
- 예문 1: 춥다 -> 추워요 (겨울은 날씨가 추워요.)
- 예문 2: 맵다 -> 매워요 (떡볶이가 조금 매워요.)
- 주의: '입다, 잡다, 좁다, 씹다'는 규칙 동사/형용사입니다. (입어요, 잡아요, 좁아요, 씹어요)

* 'ㄷ' 불규칙 (ㄷ Irregular)
- 규칙: 어간의 끝 자음 'ㄷ'이 모음을 만나면 'ㄹ'로 바뀝니다.
- 예문 1: 듣다 -> 들어요 (매일 한국어 음악을 들어요.)
- 예문 2: 걷다 -> 걸어요 (공원을 같이 걸어요.)
- 주의: '받다, 닫다, 믿다'는 규칙 동사입니다. (받아요, 닫아요, 믿어요)

* '르' 불규칙 (르 Irregular)
- 규칙: 어간의 끝 모음 '르'가 '아/어'를 만나면 '르'가 없어지고 'ㄹ라/ㄹ러'로 바뀝니다.
- 예문 1: 빠르다 -> 빨라요 (비행기가 아주 빨라요.)
- 예문 2: 부르다 -> 불러요 (노래방에서 노래를 불러요.)

[3단계: 살짝 까다로운 불규칙 ('ㅎ', 'ㅅ')]
* 'ㅎ' 불규칙 (ㅎ Irregular)
- 규칙: 어간의 끝 자음 'ㅎ'이 '아/어'를 만나면 'ㅎ'이 없어지고 모음이 '애/얘'로 바뀝니다. (주로 색깔이나 상태를 나타낼 때 씁니다.)
- 예문 1: 파랗다 -> 파래요 (하늘이 정말 파래요.)
- 예문 2: 그렇다 -> 그래요 (아, 정말 그래요?)
- 주의: '좋다, 많다'는 규칙 형용사입니다. (좋아요, 많아요)

* 'ㅅ' 불규칙 (ㅅ Irregular)
- 규칙: 어간의 끝 자음 'ㅅ'이 모음을 만나면 'ㅅ'이 사라집니다. ('ㅅ'이 사라져도 '아/어'는 그대로 씁니다.)
- 예문 1: 낫다 -> 나아요 (감기가 빨리 나아요.)
- 예문 2: 짓다 -> 지어요 (강아지가 예쁜 표정을 지어요.)
- 주의: '웃다, 씻다, 벗다'는 규칙 동사입니다. (웃어요, 씻어요, 벗어요)


[카테고리 3: 동음이의어 (난이도: 중급 3~4급)]
* 동음이의어 활용의 차이

[1단계: 초급 필수 어휘 (2급 수준)]
* 묻다 (Mut-da)
- ㄷ 불규칙 (질문하다 / to ask): 모르는 것이 있으면 선생님께 [물어요].
- 규칙 (땅에 파묻다, 얼룩이 생기다 / to bury, to be stained): 옷에 커피가 [묻어요].

* 걷다 (Geot-da)
- ㄷ 불규칙 (다리로 이동하다 / to walk): 매일 아침 공원을 [걸어요].
- 규칙 (소매를 올리다, 빨래를 거두다 / to roll up, to gather): 비가 와서 빨래를 [걷어요].

* 굽다 (Gup-da)
- ㅂ 불규칙 (고기나 빵을 불에 익히다 / to bake, to roast): 삼겹살을 맛있게 [구워요].
- 규칙 (허리나 등이 휘어지다 / to be bent): 할머니는 허리가 [굽어요].

[2단계: 중급/고급 심화 어휘 (4급 이상 수준)]
* 곱다 (Gop-da)
- ㅂ 불규칙 (예쁘다, 아름답다 / to be beautiful): 한복 색깔이 정말 [고와요]. (주의: '우'가 아니라 '오'로 바뀝니다!)
- 규칙 (추워서 손가락이 얼어 감각이 없다 / to be numb): 날씨가 추워서 손가락이 [곱아요].

* 이르다 (I-reu-da)
- '르' 불규칙 (시간이 빠르다, 누군가에게 말해주다 / to be early, to tell): 아직 포기하기엔 [일러요]. / 선생님한테 다 [일러요]!
- '러' 불규칙 (목적지에 도착하다 / to arrive): 마침내 산 정상에 [이르러요].

* 누르다 (Nu-reu-da)
- '르' 불규칙 (버튼을 압박하다 / to press): 엘리베이터 버튼을 [눌러요].
- '러' 불규칙 (색깔이 황금빛으로 노랗다 / to be yellow): 가을 들판이 [누르러요].
